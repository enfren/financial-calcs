# Financial Calculations

Python scripts for core Time Value of Money (TVM) calculations.
Built as a learning project — each script uses user input and
real calendar dates.

## Programs

| File | Description |
|------|-------------|
| `savings_basic.py` | Single deposit, daily compounding, exact calendar days |
| `checking_with_interest.py` | Interest with a balance cap, multiple balance segments |
| `cd_fixed.py` | Fixed-term CD with monthly interest payout projection |

## How to Run

```bash
python3 savings_basic.py
